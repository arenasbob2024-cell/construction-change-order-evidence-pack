Privacy

Your project file stays in your browser.

This page explains what is processed, what is stored, and what the static host can see. Last reviewed: November 4, 2026.

Short version

  • No account, email address, contact form, payment form or newsletter signup.
  • No analytics script, advertising script, cookie or third-party request.
  • Project fields and photos are processed in the browser and are never uploaded by this tool.
  • The page’s Content-Security-Policy sets connect-src 'none', so the page itself cannot make outbound data connections.
  • Refreshing or closing the page clears the form and the attached photos from the page. The only files that remain are the PDF and manifest you download.

What is processed in your browser

The project name, change order number, date, contractor, client, work description, reason, amount, schedule impact, notes and photo captions are used to draw a PDF. The PDF is produced locally with a small built-in writer; the text is not sent to a server for rendering.

Photos are decoded by the browser, drawn to a canvas, resized so the long edge is at most 1600 pixels, and encoded as a new JPEG at quality 0.85. Canvas encoding does not carry the source EXIF block, so GPS coordinates and other camera metadata are not included in the embedded copy. This process changes the image bytes and may reduce detail. The original files are not uploaded or retained by the tool; keep them separately if you need the original capture data.

Checksums and the manifest

The PDF’s SHA-256 is computed with the browser’s Web Crypto API. The downloaded manifest contains the PDF filename, byte size and hash, plus the project and change order labels you entered. The manifest is a local file you control; it is not sent anywhere by this page.

The hash is an integrity check for the exported PDF. It is not a trusted timestamp and does not certify who created the file or whether its contents are accurate.

Local counters

To keep a minimal record without tracking people, the page can store four numeric counters in your browser’s localStorage under the key coep_local_stats_v1:

  • pack_generated — a pack was generated on this device;
  • verify_run — a file check was run;
  • verify_match — a check matched;
  • useful_click — the “This was useful” button was used.

These are numbers only. They never include a project name, amount, note, photo, filename, hash or location, and they are never transmitted. Clearing site data in your browser removes them. If storage is unavailable, the counters simply do not persist.

Hosting and standard logs

The site is served as static files by Vercel. Like most hosting providers, Vercel may process standard request metadata — such as IP address, user agent, requested path and timestamp — to deliver the site, prevent abuse and keep service logs. This site does not add an analytics product and does not have a dashboard that associates those requests with your project data. Because your project fields and photos never leave the browser, they are not part of any request.

What this page does not do

  • It does not sell, rent or share personal information.
  • It does not create user profiles or set advertising cookies.
  • It does not ask for a phone number, email address or payment details.
  • It does not upload photos for “processing” or “verification”.

Changes

If the data handling changes, this page will be updated before the change ships. The review date at the top shows the last revision. This is an independent tool; there is no account to delete because there are no accounts.

Questions about the boundary between a record and a legal exhibit are not answered by this page. Consult a qualified professional for your situation.
